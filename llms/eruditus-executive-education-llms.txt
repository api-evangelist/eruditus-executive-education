# Eruditus (Emeritus)

> Eruditus Group is an online executive-education company founded in 2010 and headquartered in Singapore, operating under the Eruditus and Emeritus brands. It partners with 80+ universities — MIT, Harvard, Columbia, Wharton, Cambridge, INSEAD, IIM, NUS, HKUST and others — to deliver executive programs, professional certificates, short courses and degrees to 350,000+ learners in 80+ countries. Its public API surface is a small partner-facing REST estate: a Leads API for submitting B2C and B2B enrollment inquiries, and a Programs API for reading programs, partner schools and landing page templates. Both are authenticated with static tokens issued by Emeritus, and both offer a staging and a production environment.

This file was generated by API Evangelist from the provider's public surface on 2026-08-04. Emeritus does not publish an llms.txt (https://emeritus.org/llms.txt and the docs host both return 404).

## APIs

- [Emeritus Leads API](https://emeritus-tech.github.io/emeritus-api-docs/api/v1/leads_api/generic_lead.html): POST /api/v1/generic_lead — submit an enrollment lead. Auth header `LEAD_WEBHOOK_KEY`. Send `inquiring_for: "team"` plus `company` and `number_of_participans` for the B2B/team flow.
- [Emeritus Programs API](https://emeritus-tech.github.io/emeritus-api-docs/api/v1/programs_api/programs.html): GET /api/v1/programs_api/{programs,schools,landing_page_templates} — read the program catalog. Auth header `HTTP-EE-RESOURCES-API-KEY`.

Base URLs: production `https://admissions.emeritus.org/api/v1/`, staging `https://staging.emerituss.org/api/v1/`.

## Notes for agents

- API keys are not self-service. Emeritus issues them manually: "We will provide your own token to use in the requests. Please contact us if you need one."
- There is no OAuth, no OpenID Connect, no MCP server, no A2A agent card and no /.well-known/ discovery surface on any Emeritus host (all probed 404 on 2026-08-04).
- There is no idempotency contract. `POST /api/v1/generic_lead` is not safe to retry blindly — a repeat is expected to create a second lead.
- No rate-limit policy or headers are published.
- The Programs API publishes paths and auth but no request parameters and no response schemas, so its outputs cannot be typed in advance.
