Eruditus Group is an online executive-education company founded in 2010 by Ashwin Damera and
Chaitanya Kalipatnapu and headquartered in Singapore, operating under the **Eruditus** and
**Emeritus** brands. It partners with more than 80 top-tier universities — MIT, Harvard,
Columbia, Wharton, Cambridge, INSEAD, IIM, NUS, HKUST and others — to deliver senior executive
programs, professional certificates, short courses and degree programs to more than 350,000
learners across 80+ countries.

## Public API surface

Emeritus publishes a small partner-facing REST estate, documented at
[emeritus-tech.github.io/emeritus-api-docs](https://emeritus-tech.github.io/emeritus-api-docs/)
(source repo: [emeritus-tech/emeritus-api-docs](https://github.com/emeritus-tech/emeritus-api-docs)):

| API | Surface | Auth header |
|---|---|---|
| **Leads API** | `POST /api/v1/generic_lead` — B2C and B2B/team enrollment inquiries | `LEAD_WEBHOOK_KEY` |
| **Programs API** | `GET /api/v1/programs_api/{programs,schools,landing_page_templates}` | `HTTP-EE-RESOURCES-API-KEY` |

Environments: production `https://admissions.emeritus.org/api/v1/`, staging
`https://staging.emerituss.org/api/v1/`. Tokens are issued manually by Emeritus — there is no
self-service signup.

Emeritus publishes **no OpenAPI document**. The specs in `openapi/` were generated by API
Evangelist from the provider's published HTML reference and confirmed against live endpoints;
every path, field, example and error body is transcribed from that reference. See each spec's
`x-evidence` block.

### Known gaps on the provider side

- The Programs API reference pages still carry the documentation template's placeholder content
  (`param / This is a param description`, `{"example":"response"}`), so no request parameters
  and no success response schemas are published for those three resources.
- No idempotency contract on the single write operation.
- Two inconsistent error envelopes on one endpoint (400 flat `error`, 422 nested `errors`).
- No rate-limit policy, no deprecation/sunset policy, no changelog, no `/.well-known/` surface.
